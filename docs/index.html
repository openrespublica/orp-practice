🔐

AES-XTS-512 Encrypted Vault

All records are stored in a LUKS2 encrypted drive with Argon2id key derivation. Physical possession of the hardware key is required to decrypt.

🔗

SHA-256 Hash Chain

Each record links cryptographically to the previous one. Any tampering with a record breaks all subsequent chain hashes — making falsification detectable.

✍️

Ed25519 GPG Signing

Every record is digitally signed with a 30-day rotating Ed25519 key. The signature proves the record was created by the authorised operator.

🌐

Public GitHub Ledger

Signed JSON records are pushed to this public repository automatically. Anyone can verify a document's authenticity without contacting the issuing office.

📄

Stamped PDF Archive

Every issued document carries a footer stamp with a control number, sequence, hash, chain hash, timestamp, and QR code linking to this verification portal.

⚖️

RA 10173 Compliant

Data handling follows the Data Privacy Act of 2012. Only the document fingerprint (hash) is published — the document itself stays encrypted in the vault.
